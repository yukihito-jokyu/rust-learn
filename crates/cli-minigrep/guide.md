# cli-minigrep - ファイル検索ツール

## 概要

`minigrep` は、指定したファイル内から文字列を検索するシンプルなCLIツールです。Rustの公式ドキュメント「The Rust Programming Language」のミニプロジェクトをベースにしつつ、より実践的な機能を盛り込んでいます。

## コマンド仕様

```bash
# 基本的な検索（大文字小文字を区別する）
minigrep <query> <filename>

# 大文字小文字を区別しない検索（環境変数を設定）
IGNORE_CASE=1 minigrep <query> <filename>
```

### 引数

| 引数 | 説明 |
|------|------|
| `query` | 検索したい文字列 |
| `filename` | 検索対象のファイルパス |

### 環境変数

| 変数名 | 説明 |
|--------|------|
| `IGNORE_CASE` | `1` または `true` を設定すると、大文字小文字を区別せずに検索する |

## 要件

1. **コマンドライン引数の取得**: `std::env::args` を使用して引数をパースする
2. **ファイルの読み込み**: `std::fs::read_to_string` でファイル内容を取得する
3. **検索処理**: 検索文字列に一致する行を抽出する
4. **大文字小文字の区別**: 環境変数 `IGNORE_CASE` に応じて検索の動作を切り替える
5. **エラーハンドリング**:
   - 引数が不足している場合のエラーメッセージ
   - ファイルが存在しない場合のエラーメッセージ
   - `Result<T, E>` を適切に使用したエラー伝播
6. **結果の出力**: 一致した行を標準出力に表示する

## 使用するクレート

| クレート | 用途 | Cargo.toml の記述 |
|----------|------|-------------------|
| （標準ライブラリのみ） | 基本実装は標準ライブラリのみで完結 | なし |
| `regex` | 発展課題: 正規表現による検索 | `regex = "1"` |

## 実装ステップ

1. **Step 1**: コマンドライン引数を受け取って表示する
2. **Step 2**: ファイルを読み込んで内容を表示する
3. **Step 3**: 検索関数を実装する（大文字小文字区別あり）
4. **Step 4**: 環境変数で大文字小文字の切り替えを実装する
5. **Step 5**: エラーハンドリングを整える
6. **Step 6**: ロジックを `lib.rs` に切り出して `main.rs` をスリムにする
7. **Step 7**: テストを書く
8. **Step 8（発展）**: `regex` クレートを使った正規表現検索を追加する

## 発展課題

- 検索結果に行番号を付与する
- 複数ファイルの同時検索に対応する
- 検索結果のハイライト表示（ANSIエスケープシーケンス）
- `clap` を使ったよりリッチなCLI引数解析への移行
- 標準入力（パイプ）からの入力に対応する
