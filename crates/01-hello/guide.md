## 内容

### Hello World

Rustプログラムのエントリポイントは `main` 関数です。

```rust
fn main() {
    println!("Hello, world!");
}
```

- `fn` キーワードで関数を宣言
- `println!` はマクロ（`!` がついているのがマクロの証）
- 文はセミコロン `;` で終わる

### コメント

Rustには3種類のコメントがあります。

```rust
// 行コメント: 行末までがコメント扱い

/* ブロックコメント:
   複数行にわたるコメント */

/// ドキュメンテーションコメント: 関数や構造体のドキュメントを生成
/// Markdown記法が使える
fn documented_function() {
    // 処理
}

//! モジュールドキュメンテーションコメント
//! モジュール全体の説明を書く
```

- `//` --- 行コメント。行末までが無視される
- `/* ... */` --- ブロックコメント。囲まれた範囲が無視される（ネスト可能）
- `///` --- ドキュメンテーションコメント。次のアイテムのドキュメントになる
- `//!` --- モジュールドキュメンテーションコメント。囲んでいるアイテムのドキュメントになる

### フォーマット出力

`print!` と `println!` マクロでフォーマット出力ができます。

```rust
fn main() {
    // 基本的な出力
    println!("Hello, world!");

    // 改行なし
    print!("改行なし");
    print!("で連続して出力");

    // フォーマット文字列（{} で変数を埋め込む）
    let name = "Rust";
    println!("Hello, {}!", name);

    // 複数の引数
    let x = 5;
    let y = 10;
    println!("x = {}, y = {}", x, y);

    // 位置引数
    println!("{0}と{1}と{0}", "Alice", "Bob");

    // 名前付き引数
    println!("{name}は{age}歳です", name = "太郎", age = 25);

    // デバッグ出力（{:?}）
    let arr = [1, 2, 3];
    println!("配列: {:?}", arr);

    // Prettyデバッグ出力（{:#?}）
    let person = ("山田", 30);
    println!("人物: {:#?}", person);

    // 2進数、8進数、16進数
    println!("2進数: {:b}", 10);
    println!("8進数: {:o}", 10);
    println!("16進数: {:x}", 10);
    println!("16進数(大文字): {:X}", 10);

    // 幅とアラインメント
    println!("{:>5}", 42);      // 右揃え、幅5
    println!("{:<5}", 42);      // 左揃え、幅5
    println!("{:^5}", 42);      // 中央揃え、幅5
    println!("{:05}", 42);      // ゼロ埋め、幅5

    // 標準エラー出力
    eprintln!("エラー: 何か問題が発生しました");
}
```

#### フォーマットマクロの種類

| マクロ | 出力先 | 改行 |
|--------|--------|------|
| `print!` | 標準出力 | なし |
| `println!` | 標準出力 | あり |
| `eprint!` | 標準エラー | なし |
| `eprintln!` | 標準エラー | あり |
| `format!` | 文字列を返す | - |

#### 主なフォーマット指定子

| 指定子 | 説明 | 例 |
|--------|------|-----|
| `{}` | Display出力 | `println!("{}", 42)` |
| `{:?}` | Debug出力 | `println!("{:?}", arr)` |
| `{:#?}` | Pretty Debug出力 | `println!("{:#?}", person)` |
| `{:b}` | 2進数 | `println!("{:b}", 10)` |
| `{:o}` | 8進数 | `println!("{:o}", 10)` |
| `{:x}` | 16進数(小文字) | `println!("{:x}", 255)` |
| `{:X}` | 16進数(大文字) | `println!("{:X}", 255)` |
| `{:>N}` | 右揃え(幅N) | `println!("{:>5}", 42)` |
| `{:<N}` | 左揃え(幅N) | `println!("{:<5}", 42)` |
| `{:^N}` | 中央揃え(幅N) | `println!("{:^5}", 42)` |
| `{:0N}` | ゼロ埋め(幅N) | `println!("{:05}", 42)` |
